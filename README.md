# Прогнозирование свойств композиционных материалов

Учебный проект: по свойствам компонентов композита (связующего и армирующего наполнителя) спрогнозировать **модуль упругости** и **прочность при растяжении**, а также рекомендовать **соотношение матрица-наполнитель** с помощью нейронной сети.

## Главный результат

Построен полный пайплайн: EDA, очистка и предобработка, 6 моделей ML с подбором гиперпараметров, нейронная сеть, Streamlit-приложение. Но ни одна модель не превосходит наивный прогноз средним значением. Дальнейшая проверка показала, что причина в данных, а не в моделях:

- **Перестановочный тест** не находит связи признаков с целевыми переменными, пригодной для прогноза (p = 0,13–0,83).
- **Взаимная информация** показывает лишь очень слабые зависимости (MI ≤ 0,1), которые модели не могут обратить в выигрыш в прогнозе.
- **8 архитектур нейросети** (от 16 нейронов до 256-128-64, с регуляризацией и без) не обходят baseline. Регуляризация лишь приближает сеть к прогнозу средним.

**Вывод:** для прогноза нужны другие данные, а не другая модель.

## Результаты

Повторная кросс-валидация 5 блоков × 3 повтора:

| Модель | Модуль упругости | Прочность |
|---|---|---|
| **Baseline (среднее)** | **−0,008** | **−0,007** |
| Линейная регрессия | −0,016 | −0,014 |
| k ближайших соседей | −0,018 | −0,019 |
| Случайный лес | −0,032 | −0,015 |
| Градиентный бустинг | −0,041 | −0,017 |
| HistGradientBoosting | −0,025 | −0,016 |

Соотношение матрица-наполнитель (нейронная сеть, кросс-валидация 5 блоков): лучшая архитектура R² = −0,009, MAE 0,732, baseline R² = −0,006, MAE 0,730.

Перестановочный тест (случайный лес, 100 перестановок):

| Целевая переменная | R² на настоящих данных | R² на перемешанных | p-значение |
|---|---|---|---|
| Модуль упругости | −0,066 | −0,050 | 0,83 |
| Прочность | −0,039 | −0,054 | 0,13 |
| Соотношение матрица-наполнитель | −0,045 | −0,055 | 0,27 |

## Приложение

Streamlit-приложение принимает параметры композита и выдаёт прогнозы. Рядом показано отклонение от среднего и сравнение с baseline, а предупреждение объясняет, что модели не лучше прогноза средним. Приложение демонстрирует пайплайн, а не инструмент для подбора реальных материалов.

## Структура

```
├── data/                     исходные данные (X_bp.xlsx, X_nup.xlsx)
├── notebooks/
│   └── composites_research.ipynb   всё исследование
├── src/data.py               загрузка и подготовка данных (общая для всех частей)
├── models/                   обученные модели и metrics.json
├── train_models.py           обучение моделей для приложения
├── app.py                    Streamlit-приложение
├── requirements.txt
└── environment.yml
```

## Запуск

```bash
pip install -r requirements.txt        # или: conda env create -f environment.yml
streamlit run app.py                   # приложение
python train_models.py                 # переобучить модели
jupyter notebook notebooks/composites_research.ipynb
```

## Данные

1023 записи о составе и свойствах композитов в двух таблицах, объединённых по `id`. После удаления одной ошибочной записи (нулевая плотность нашивки) остаётся 1022 наблюдения, 11 входных признаков и 2 целевые переменные.

Python, pandas, NumPy, scikit-learn, TensorFlow/Keras, Matplotlib, Seaborn, Streamlit
